Справка

Как подключиться к EndlessNet

Здесь только то, что нужно пользователю: войти в админку, выбрать сеть, установить клиент, подключить устройство и проверить, что оно в сети.

Старт

EndlessNet создаёт частную WireGuard-совместимую сеть для ваших устройств. Ежедневная работа проходит в админке: там видны сети, устройства, статусы и готовые команды подключения.

Нужен доступ к админке Откройте админку и войдите через доступный провайдер авторизации.
Нужна выбранная сеть Используйте существующую сеть или создайте новую в разделе “Сети”.

Админка

После входа доступны четыре рабочих раздела:

  • Обзор — состояние сетей и устройств.
  • Сети — создание сети, CIDR и DNS.
  • Устройства — список узлов выбранной сети.
  • Доступ — команды установки и подключения клиента.

Установка клиента

Для Debian и Ubuntu используйте APT-репозиторий UNNG. Для других систем откройте раздел “Доступ” в админке и скопируйте команду для своей платформы. 

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.unng.ru/apt/unng.gpg | sudo tee /etc/apt/keyrings/unng.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/unng.gpg] https://apt.unng.ru/apt stable main" | sudo tee /etc/apt/sources.list.d/unng.list
sudo apt update
sudo apt install -y endlessnet-client
Windows Используйте endlessnet-client.exe и PowerShell-команды из раздела “Доступ”.
Android и iOS Импортируйте сгенерированный wg-endlessnet.conf в официальное приложение WireGuard.

Подключение устройства

Самый простой путь — скопировать готовую команду из раздела “Доступ”. Если подключаете вручную через CLI, нужны адрес сервера, токен входа, имя сети и имя устройства.

1. Выберите сеть Откройте “Сети” или “Устройства” и выберите рабочую сеть.
2. Скопируйте команду В разделе “Доступ” команды уже подставлены под выбранную сеть.
3. Подключите устройство Выполните login, затем up на подключаемой машине.
4. Проверьте статус Устройство должно появиться в списке с адресом и временем активности. 
endlessnet-client login --server <server-url> --token <token>
endlessnet-client up --network <network> --hostname <hostname> --output ./wg-endlessnet.conf

Проверка и обслуживание

Используйте эти команды, когда нужно проверить состояние, обновить локальный WireGuard-конфиг или отключить устройство.

Показать статус endlessnet-client status --json
Обновить конфиг endlessnet-client sync --output ./wg-endlessnet.conf
Отключить локально endlessnet-client down --output ./wg-endlessnet.conf
Выйти и отозвать устройство endlessnet-client logout

Безопасность

  • Не передавайте посторонним session token, join token и файл wg-endlessnet.conf.
  • Не копируйте один клиентский конфиг на несколько устройств.
  • Если устройство потеряно или передано другому пользователю, выполните logout или удалите его из админки.
  • На Unix-системах храните клиентский конфиг доступным только владельцу файла.
